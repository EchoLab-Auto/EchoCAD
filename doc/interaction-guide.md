## 3D 视口导航

### 视图模式（非草图编辑时）

| 操作 | 方式 |
|------|------|
| 旋转视图 | 鼠标左键拖拽 |
| 平移视图 | 鼠标中键拖拽 / Shift+左键 |
| 缩放视图 | 鼠标滚轮 |
| 前视图 | 点击工具栏「前」按钮 |
| 上视图 | 点击工具栏「上」按钮 |
| 右视图 | 点击工具栏「右」按钮 |
| 等轴测 | 点击工具栏「3D」按钮 |
| 适配视图 | 点击工具栏「⊞」按钮 |
| 线框模式 | 点击工具栏「线框」按钮 |
| 边线显示 | 点击工具栏「边线」按钮 |

### 草图编辑模式下的视口

进入草图编辑后，视口自动对齐到草图平面。视口上方出现「↩ 平面」按钮可重新对齐。

- **选择工具**：可自由旋转视图 + 选择/拖拽草图实体
- **绘制工具**（直线/圆/弧线等）：视口锁定旋转，鼠标操作用于绘制

## 草图编辑

### 进入和退出

| 操作 | 方式 |
|------|------|
| 进入草图编辑 | 特征树中**双击**草图特征，或右键点击 →「编辑草图」 |
| 退出草图编辑 | 点击工具栏 **✕ 退出草图** 按钮，或 Esc（选择工具状态下再按一次），或左键点击其他特征 |
| 新建草图 | 菜单 编辑 → 新草图，或按 `N` 键（新建后自动进入编辑） |

退出草图后恢复完整 3D 旋转控制。草图轮廓在 3D 视口中保持可见（便于定位
后续特征），但不可编辑。

### 绘制工具

所有绘制操作通过鼠标在 3D 视口中完成（光线投射至草图平面）。

#### 选择 (Esc)
- **单击实体**：选中该实体（右侧显示属性）
- **单击空白处**：取消选中
- **拖拽点**：移动点位置，自动求解约束

#### 直线 (L)
- **单击**：放置起点
- **继续单击**：连续放置端点，形成多段线
- **右键 / 双击**：结束当前线段

绘制时光标会自动吸附到：端点、中点、圆心、交点、网格点、切线点。
按住时会显示与标准角度（0°/45°/90°…）的角度吸附。

#### 圆 (C)
- **第一次单击**：放置圆心
- **移动鼠标**：实时预览圆的半径
- **第二次单击**：确认半径并完成圆
- **右键**：取消绘制

#### 弧线 (A) — 三步绘制
- **第一步**：单击放置圆心
- **第二步**：移动鼠标预览半径，单击确认半径和起始角度
- **第三步**：移动鼠标预览弧线，单击确认终止角度
- **右键**：取消绘制

#### 矩形 (R)
- **第一次单击**：放置第一个角点
- **移动鼠标**：预览矩形尺寸（实时显示宽×高）
- **第二次单击**：确认对角点，自动生成 4 条边

#### 样条 (B)
- **连续单击**：添加控制点
- **右键 / 双击**：完成样条曲线
- 至少需要 2 个控制点才能完成

#### 椭圆 (I)
- **第一次单击**：放置椭圆中心
- **移动鼠标**：预览长轴方向
- **第二次单击**：确认长轴端点（默认短轴比 0.5）

### 智能吸附

绘制时自动检测并吸附到以下位置：

| 吸附类型 | 图标颜色 | 说明 |
|---------|---------|------|
| 端点 | 黄色 | 现有点的位置 |
| 中点 | 绿色 | 线段的中间点 |
| 圆心 | 红色 | 圆/弧的圆心 |
| 交点 | 粉色 | 两条线的交点 |
| 网格 | 灰色 | 最近的整数坐标网格点 |

### 构造线

在右侧属性面板中，选中一条线或圆后勾选「构造线」复选框，即可将其标记为构造线（虚线显示）。构造线不参与拉伸/旋转等特征操作。

## 约束

选中草图实体后，通过工具栏「约束 ▾」菜单添加约束：

| 约束 | 说明 | 选中要求 |
|------|------|---------|
| 水平 | 线段变为水平 | 1 条线 |
| 竖直 | 线段变为竖直 | 1 条线 |
| 平行 | 两条线平行 | 2 条线 |
| 垂直 | 两条线垂直 | 2 条线 |
| 相切 | 线与圆相切 | 1 线 + 1 圆 |
| 同心 | 两圆圆心相同 | 2 个圆 |
| 相等 | 长度或半径相等 | 2 条线 或 2 个圆 |
| 中点 | 点位于线段中点 | 1 点 + 1 线 |
| 固定 | 固定点位置 | 1 个点 |
| 角度 | 两条线夹角固定 | 2 条线（默认 90°） |
| 直径 | 圆的直径固定 | 1 个圆 |
| 距离 | 两点距离固定 | 2 个点（默认 2.0） |
| 求解 | 执行约束求解 | 自动 |

约束添加后自动执行一次求解。也可手动点击「求解」或按 `S` 键重新求解。

## 特征操作

所有特征操作基于当前活跃的草图。操作完成后**保持在草图编辑模式**，可继续绘制或创建更多特征。

### 拉伸 (E)

1. 点击工具栏「特征 ▾」→「拉伸」
2. 右侧属性面板显示拉伸配置
3. 3D 视口实时显示**橙色半透明预览**
4. 调整参数：
   - **方向**：单侧 / 中平面 / 双向
   - **深度**：滑块或输入数值
   - **拔模角**：0° ~ 15°
5. 点击「确认拉伸」

#### 拉伸选区（多轮廓草图）

当草图包含多个封闭轮廓（例如两个同心圆、矩形内的圆孔、多个独立形状）时，
面板下方会出现「拉伸选区」列表：

- 每个闭环是一个可选区域，按面积从大到小排列，显示面积数值
- **单击**切换选中；「全选」/「取消」批量操作
- 不选中任何区域 = 拉伸全部轮廓（默认行为）
- 选中多个嵌套轮廓时，外轮廓与内轮廓自动组成**带孔实体**
  （例如选中两个同心圆 → 挤出圆环）
- 只选内圆 → 挤出实心圆柱；只选外圆 → 挤出带大孔的薄壁件

### 旋转 (W)

1. 选中一条线作为旋转轴（可选，默认使用 Y 轴）
2. 点击「特征 ▾」→「旋转」
3. 自动创建 360° 旋转特征

### 扫描

需要两个草图：
1. 轮廓草图（当前活跃的）
2. 路径草图（其他任一草图）
3. 点击「特征 ▾」→「扫描」

### 圆角 / 倒角

对实体添加圆角或倒角特征：
1. 选中目标实体后点击「特征 ▾」→「圆角」(F) 或「倒角」
2. 默认作用于全部锐边；也可进入**拾边模式**手动选择特定边
   （视口中悬停高亮黄色，点击选中变蓝，右侧面板确认）
3. 默认半径/距离 0.5，可在属性面板调整参数

### 抽壳

对最近创建的实体添加抽壳特征（向内偏移壁厚）：
1. 点击「特征 ▾」→「抽壳」
2. 默认壁厚 0.5

### 布尔运算

对两个实体进行布尔操作：
1. 点击「特征 ▾」→「布尔运算」
2. 在对话框中选择操作类型（并集 / 差集 / 交集）与目标 A、B（可互换）
3. 确认后生成布尔特征

### 阵列

阵列与镜像参数创建后可在属性面板再次编辑（数量、间距、角度、镜像面）。

#### 线性阵列
沿指定方向重复 N 个副本，间距可调

#### 圆周阵列
绕指定轴重复 N 个副本，总角度可调（默认 360°）

#### 镜像
关于指定平面镜像（法向量 + 平面上一点）

## 特征树管理

| 操作 | 方式 |
|------|------|
| 选中特征 | **单击**特征名称（仅选中，不进入编辑） |
| 进入草图编辑 | **双击**草图特征，或右键 →「编辑草图」 |
| 右键菜单 | 右键点击特征名称 |

> **选择 ≠ 编辑**：左键单击草图只是选中它（属性面板显示其信息），
> 不会进入草图编辑模式。只有双击或右键菜单才会进入编辑——
> 这与 SolidWorks 的行为一致。

右键菜单选项：
- **编辑草图**：进入该草图的编辑模式
- **正视于草图**：将相机对齐到该草图平面
- **重命名**：修改特征名称
- **抑制 / 取消抑制**：跳过该特征的再生
- **删除**：删除该特征（有依赖时提示级联）

## Agent API（自动化接口）

除 UI 外，EchoCAD 的所有建模操作均可通过 `AgentCAD` 编程接口调用
（`app/src/commands/agent-api.ts`，导出单例 `cad`）。设计原则 #14
（API 完备性）要求：UI 能做的，API 都能做。

```ts
import { cad } from "@/commands/agent-api";

const sketch = await cad.newSketch("xy");
await cad.rectangle(0, 0, 40, 30);
await cad.circle(20, 15, 5);
const regions = await cad.getExtrudeRegions();       // 选区（同心轮廓）
const body = await cad.extrude(sketch, 10, 0, regions.map(r => r.index));
await cad.fillet(body, 1.0);
await cad.shell(body, 1.0);
const props = await cad.massProperties(body);        // { volume, surfaceArea, centroid }
const screenshot = await cad.captureViewport();      // base64 PNG，用于视觉自检
await cad.exportStl();
```

覆盖范围：草图绘制、约束、拉伸/旋转/扫描、圆角/倒角（含拾边）、抽壳、
布尔、阵列/镜像（含参数编辑）、特征抑制/重命名/颜色、测量与质量属性、
插件生成器、导入导出、撤销重做、视口截图、B-rep 开关。
完整方法表见 `agent-api.ts` 头部注释。
